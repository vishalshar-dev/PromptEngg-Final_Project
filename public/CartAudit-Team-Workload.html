3. Anticipated Faculty Q&A Matrix

Question Speaker Concise Technical Answer
How is user data stored and kept private? Member 3 Saved immediately in browser localStorage (cartaudit-store) for offline speed. Signed-in users sync across devices via Firebase Auth + Cloud Firestore scoped to /users/{uid}/... with strict firestore.rules.
How are Gemini API keys secured? Member 2 All Gemini SDK calls run server-side inside server.ts via /api/* endpoints; API keys never ship in client bundles. If the backend is unreachable, Penny falls back to the local TypeScript engine.
How do you avoid floating-point errors in splits? Member 1 splitLedgerEngine.ts normalizes currency to integer paise and distributes remainders deterministically so participant shares always equal the exact bill total.
How did you verify the financial calculations? Member 3 Core math is decoupled from React components into pure TypeScript engines tested by 96 automated unit tests across 15 test files, alongside TypeScript strict checks (tsc --noEmit).
